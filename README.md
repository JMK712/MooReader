# 静读

适用于 `https://jinghecx.com/responsive/read?...` 的 Chrome 阅读模式扩展，兼容嵌入式阅读框和正文直接显示在当前页面的两种布局。点击工具栏中的扩展图标打开或关闭。界面提供字号、行距、段落间距、正文宽度、字体、三种预设配色，以及背景色、文字色和强调色的自定义色值。另有阅读进度和原页面支持时的“下一章”。按 `Esc` 退出。

网页里的“注”会显示成小按钮。点击可查看注释，再次点击、点浮层关闭按钮或按 `Esc` 可收起。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
4. 打开目标阅读页，待章节正文出现后，点击“静读”扩展图标。

如果已安装旧版，在 `chrome://extensions` 找到“静读”并点击刷新，然后刷新阅读页。新版会保留原有阅读偏好。

如需便于使用，可在 Chrome 工具栏的扩展菜单中固定“静读”。

## 工作方式

部分图书使用嵌入式阅读框，正文在 `wx-hz.book.qq.com` 的跨域框架中；另一些图书直接在当前页面显示正文。本扩展会从当前布局提取已显示的章节，再显示独立阅读界面。章节内容不会发送到扩展作者的服务器；偏好设置仅存于浏览器本地。

扩展只能整理网站已经向当前浏览器显示的内容。若网站提示登录失败或正文尚未加载，阅读模式也无法取得章节。网站若修改页面结构，可能需要更新正文提取规则。
